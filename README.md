## 单日导出使用

先运行 `browser_control.ipynb` 建立 Selenium 连接，在其打开的 Chrome 中登录。保留 Notebook 中的 `driver`。将本仓库目录加入Python导入路径，在新单元格运行：

```python
import importlib
import export_one_day

importlib.reload(export_one_day)
print(export_one_day.VERSION)

# 已成功导出的1月2日不应重复提交；下面从下一天开始。
result = export_one_day.export_one_day(
    driver,
    day="2025-01-03",
    base=r"D:\桌面\data",
    confirm=False,
)
```

`confirm=False` 预演至结算校验，不确认扣除；改为 `True` 才会在校验通过后扣除单日限量包的免费条数。日期改为实际需要导出的日期，每次只处理一天。

代码自动操作My97日历（包含跨iframe选择）、选择全国、核对已有四个关键词、勾选匹配方式、点击与重置同组的筛选确定、核对底部数量并选择正式导出入口。之后选择单日限量数据包、勾选协议并核实零元卡片、实际应付金额与条数余额。非零或不明实际应付金额、现金支付入口、条数不足或控件不唯一时停止。

关键词使用网站已有保存配置；缺少或多出关键词时停止，不自动编辑关键词弹窗。其他筛选条件应保持全部，单位输入框留空。本版本不实现多日循环、省份拆分或每天定时运行。

## 保存与恢复

文件在 `base\downloads\日期_批次编号\` 内。仅在XLSX结构完整、首个工作表非空行数符合“数据条数+1个表头”时标记完成。若没有自动下载，程序打开导出记录，等待120秒供手动点击该笔原记录的下载链接；这个回退分支尚未实现自动匹配订单。

`base\one_day_日期.json` 保存进度。提交前先写 `submitting`，发生异常不会自动重复扣除；请在网站原导出记录核对或重新下载。`downloaded` 表示成功，重跑同一天会返回原文件路径。不要删除进度来绕过重复提交保护。2025-01-01已在本会话多次导出，代码明确禁止再次自动提交。

浏览器连接若失效，需要重新连接并用新的driver创建任务。不要在扣除后盲目重跑。残留锁只有确认旧任务停止后才能清理。
